# Adhuni International - Corporate Website

A professional, high-performance corporate website for **Adhuni International General Trading & Contracting W.L.L**, a premier firm based in Kuwait specializing in Engineering, Procurement, and Construction (EPC) solutions.

## 🏢 Project Overview

This project is a modern, responsive web application designed to showcase Adhuni International's expertise in the Oil & Gas, Infrastructure, and Power sectors. It serves as a digital storefront for their contracting and trading services.

## 🚀 Key Features

- **Responsive Design:** Optimized for desktops, tablets, and mobile devices using Bootstrap 5.
- **Dynamic Animations:** Smooth scroll animations using AOS (Animate On Scroll).
- **Service Catalog:** Detailed pages for Civil, Mechanical, Electrical, and Infrastructure services.
- **Trading Portal:** Showcase of procurement capabilities and material supply.
- **Interactive Elements:** Content sliders (Swiper), statistical counters, and modern UI components.
- **Lead Generation:** Integrated PHP contact forms for business inquiries.

## 🛠️ Technical Stack

- **Frontend:** HTML5, CSS3 (SCSS), JavaScript (ES6+)
- **Framework:** [Bootstrap v5.3.5](https://getbootstrap.com/)
- **Libraries:**
  - [AOS](https://michalsnik.github.io/aos/) (Scroll Animations)
  - [Swiper](https://swiperjs.com/) (Modern Touch Sliders)
  - [PureCounter](https://github.com/srexi/purecounterjs) (Numerical Animation)
  - [Bootstrap Icons](https://icons.getbootstrap.com/)
- **Backend:** PHP (for contact form processing)
- **Template:** Based on "Scout" by BootstrapMade.
